# OctoAcme Project Management Docs

This folder contains OctoAcme's project management guidance for cross-functional projects that deliver product features, services, or integrations. Use the documents below as a shared reference throughout the project lifecycle.

## OctoAcme project management processes

OctoAcme manages cross-functional work through initiation, planning, execution, release, and closeout/retrospective. Teams validate the business need and success measures, align stakeholders, and establish an initial plan; break approved work into prioritized increments with acceptance criteria, owners, milestones, and risk/dependency tracking; deliver through the project board and small reviewed pull requests with CI and appropriate testing; release with readiness checks, smoke tests, stakeholder communications, and rollback planning; then capture learnings and track improvement actions. Project and Product Managers coordinate delivery, prioritization, risks, and communications with developers, QA, and stakeholders.
